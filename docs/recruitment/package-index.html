模型负责治理策略；路线、容量、距离和 ETA 由确定性模块计算。真实 DeepSeek 为显式开启的可选能力。

固定场景中的重规划效果

59.8%静态执行，不重规划
75.9%固定均衡策略重规划
79.6%确定性事件策略重规划

9 个固定场景 × 3 种条件；数字为各场景任务完成率的算术平均。第三项采用 MockEventAgent，不能解读为大模型收益。详细口径与历史真实模型失败分析见项目说明。

默认演示不需要 API Key 或 GPU。城市道路、车辆和运营事件为合成数据；未接入真实政府运营系统。仿真会话在内存中，认证、多人隔离和生产持久化尚未实现。此包可以离线阅读与播放；安装运行时依赖仍需联网。
