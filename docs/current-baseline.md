# CityClean-Agent 当前干净基线

原始基线日期：2026-09-23；投递整理日期：2026-10-14。当前投递资料与验证记录见 [投递说明](recruitment/README.md)。

## 定位

当前基线定位为“城市环卫资源约束智能决策仿真与评测平台”，不是已接入政府生产数据的城市管理系统。

真实性边界：

- 天地图仅提供底图和覆盖物展示，不参与道路距离、车辆路线或 ETA 计算。
- 道路网络、垃圾桶、车辆、传感器读数和运营事件由固定种子的确定性生成器产生。
- 规则与 DeepSeek 使用同一批候选事实和资源预算。
- OR-Tools 负责确定性调度，Verifier 独立验证硬约束，CitySim 是仿真状态真值来源。
- 历史比赛 fixture 只允许从 `/demo` 动态加载，不作为产品运行事实。

## 已纳入基线

- FastAPI 产品 API 与版本化契约。
- React 产品工作台和不进入默认生产构建的独立历史演示入口。
- 合成道路网络、风险分析和固定随机种子。
- 资源约束研判：候选数量、车辆数量、车辆容量和治理目标预算。
- 规则与 DeepSeek 研判证据面板。
- 两种策略分别调度后的量化对比。
- OR-Tools、Verifier、CitySim 执行和扰动后重规划。
- 可选设施 SQLite 仓储代码及地图选点界面。
- 天地图 SDK 封装及无 Key 降级。
- Docker Compose 本地合成 Demo、无 Key 合成路网展示、截图与演示视频。
- Benchmark、Gold 评测、错误分析和对抗验证资源。

上述历史训练/评测资源统一存放在 `knowledge_base/`，不会作为产品 Runtime 的状态来源。可再生成的运行结果统一写入被忽略的 `artifacts/`。

## 默认运行边界

- 合成实验链默认可用，不需要外部数据或模型 Key。
- DeepSeek 研判只有在用户显式点击且配置 `DEEPSEEK_API_KEY` 时调用。
- 默认 FastAPI 应用不注入权威 Runtime 或设施仓储，因此相关接口返回明确的 unavailable/503。
- 仿真运行会话只保存在进程内存中，服务重启后丢失。
- 当前未提供身份认证、多人隔离、后台任务队列或生产持久化。

## 验收命令

```powershell
conda activate langchain1.2
python -m pytest -q

cd frontend
npm run build
```

## 后续优化入口

后续改动应优先围绕以下方向，并保持现有事实边界：

1. 扩充资源稀缺场景和固定评测集。
2. 完善规则/模型的目标选择与最终调度收益指标。
3. 将合成、CSV、GeoJSON 和回放数据统一到显式数据源适配器。
4. 增加可部署的应用装配、持久化和运行观测。
5. 基于已有本地容器化入口，发布只读或受限的在线 Demo。

暂不把 RAG、多智能体、MCP、模型直接路线规划或真实政府接口模拟纳入本基线。
