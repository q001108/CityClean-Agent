# v0.2 冻结轨迹 provenance 记录

`deepseek_e2e_smoke_results.json` 保存了 `urgent_timing_tradeoff_live`
的闭环结果和 PolicyDecision，但没有逐轨迹所需的 `captured_at`、`model_id`、
输入哈希、契约版本和 trace ID。根据 v0.2 规格，不能依据文件名、脚本默认值或
历史结果反向补写这些字段。

该缺口已于 2026-08-26 通过一次显式授权的真实 API 调用解决。当前冻结轨迹位于
`knowledge_base/traces/v02_urgent_timing_trace.json`，来源为 `RECORDED_REAL_API`，模型标识为
`deepseek-v4-flash`；默认前端 fixture 由该轨迹生成，并在离线回放中展示 Full、Fixed、
Static 对照。冻结文件不包含 API Key、Authorization、Cookie 或 Provider 私有响应字段。

只有在需要重新采集且已获得 DeepSeek 凭据、同意产生 API 费用后，才可由开发者显式执行：

```powershell
conda run -n langchain1.2 python scripts/capture_v02_trace.py --output knowledge_base/traces/v02_urgent_timing_trace.json
```

该命令只读取环境变量中的 `DEEPSEEK_API_KEY`，不会打印或写入密钥。重新采集会产生费用，
且不得由自动化、测试或默认演示触发，也不得无意覆盖当前已验收的冻结基线。
