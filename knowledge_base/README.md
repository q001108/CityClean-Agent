# 离线知识与评测资源

本目录保存 CityClean-Agent 的版本化离线知识、历史评测输入和可审计回放资源。它不是线上产品的运行数据库，也不会自动注入模型上下文。

当前项目没有执行模型微调或训练。`gold/` 是独立评测集，不是训练集；后续若引入训练数据，必须另建目录并记录来源、许可和与评测集的去重结果。

## 目录边界

```text
knowledge_base/
  gold/          # 人工审核的治理 Gold 数据集及审计说明
  traces/        # 经 provenance 标注的历史模型轨迹
  reports/       # 基于冻结输入生成并审阅的历史分析报告
  demo/fixtures/ # 仅供独立 demo.html 历史回放使用的离线 fixture
```

## 使用规则

- 产品 API、资源约束实验台和 CitySim 默认不得读取本目录作为实时城市事实。
- Gold 数据只允许由显式评测脚本读取，不得在评测前用于针对性改写答案。
- 历史真实模型轨迹必须保留模型、时间、输入哈希和来源标识，不能冒充实时调用。
- 历史 fixture 只用于可重复展示，由 `npm run dev:demo` 显式启动；默认产品构建不引用或打包这些资源。
- 新生成的评测结果、截图和浏览器记录写入 `artifacts/`，不要提交到本目录。
- 若未来建立法规或作业规范 RAG，应新建独立子目录和来源清单，不得与 Gold 标签混用。

## 与其他数据目录的区别

- `data/`：本地运行时数据库，只保存本机可变状态并由 Git 忽略。
- `artifacts/`：可再生成的输出和 QA 产物，由 Git 忽略。
- `knowledge_base/`：需要版本控制、审计和按需复用的冻结资源。
